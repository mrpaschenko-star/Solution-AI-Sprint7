# Task1 — триаж и постановки

[18 инициатив](initiatives.md) оценены по природе задачи. Флагман №1 дополнен №2 (OCR) и №18 (извлечение показателей). [Выбор по канвасу](selection.md) учитывает ценность, данные, выполнимость и риск. [Полные постановки](formulations.md) отделяют выход модели от бизнес-действия.

Паспорта разделов 0–5 и ADR находятся в [Task2](../Task2/README.md). По остальным пятнадцати инициативам полные паспорта не создаются.

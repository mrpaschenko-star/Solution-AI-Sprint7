# Полная постановка трёх инициатив

| Поле | №1 Финмониторинг | №2 OCR | №18 Финансовые показатели |
|---|---|---|---|
| Без слова AI | История и помеченные операции → очередь с объяснённым порядком | Страница документа → проверяемые текст и координаты | Пакет документов → показатели с периодом, единицей и источником |
| Изменяемое действие | Сотрудник берёт следующий кейс по политике priority/deadline | Оператор исправляет распознанный текст вместо перепечатки | Андеррайтер подтверждает подготовленные поля вместо поиска и ввода |
| Объект / единица | Операция как anchor; связанные операции клиента показываются вместе; label и slot привязаны к anchor | Страница; результат хранится в составе версии документа | Поле `(заявка, показатель, период, валюта/единица)` и пакет |
| Момент | Микробатч каждые 15 минут, вне исполнения платежа | Асинхронно после загрузки | Асинхронно после OCR/native parse |
| Операция / модальность | Порядок/аномалия; таблица и временные окна. Назначение платежа пока не подаётся в модель | Распознавание; изображение/документ | Извлечение; текст, таблица, документ |
| Выход модели | Ненормированная anomaly score, не вероятность схемы | Tokens, boxes, engine confidence | Кандидат JSON полей с evidence IDs, abstain |
| Бизнес-выход | Рекомендация приоритета + проверяемые факты; решение только сотрудника | Редактируемый OCR слой; не проверка подлинности | Валидированные кандидаты с подсветкой, противоречия, подтверждение; не решение о кредите |
| Источник правильного ответа | Экспертный guide о необходимости проверки на available-at-time evidence; расследование и confirmed findings отдельно, с задержкой | Двойная транскрипция видимого изображения с арбитражем; нечитаемое помечается, не угадывается | Двойная экспертная разметка числа/периода/единицы/ссылки; unreadable/missing/conflict — допустимые ответы |
| Где обучаемая закономерность | Аномальность профиля; признаки/квоты/сроки/объяснения — код | OCR; загрузка/антивирус/геометрия/контракт — код | Semantic label mapping в длинном хвосте; native parsers, расчёты и gates — код |
| Конвейер | Capture → point-in-time features → score → policy merge → очередь → человек → outcomes | Upload → sandbox → render/native-text check → OCR → schema/quality gate → review | OCR/native data → selection of relevant pages → constrained model → schema/evidence/math checks → human confirm |
| Неизвестно | Качество данных, сроки РВК, risk prevalence, влияние UI на время | Типы/языки, страницы/месяц, доля плохих фото | Словарь показателей, число заявок, доля шаблонов, длительность ручных шагов |
| Альтернативное прочтение / вопрос | Автоблокировка? Не входит; подтвердить с комплаенсом scope очереди | Поисковый архив или сквозное заполнение формы? Здесь OCR контракт | Расчёт коэффициентов или extraction? Формулы считаются кодом после подтверждения исходных значений |
| Вердикт | Гибрид | Гибрид | Гибрид |

Полные [паспорта](../Task2/README.md) дополняют постановки качеством, готовностью данных и различающими экспериментами.
